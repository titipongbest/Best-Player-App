# Best Player

แอพเล่นวิดีโอ Android สไตล์ MX Player (Kotlin + Media3/ExoPlayer)

## ฟีเจอร์
- **เล่นวิดีโอคุณภาพสูง**: ใช้ ExoPlayer + hardware decoder พร้อม decoder fallback (รองรับ H.264/H.265/VP9/AV1 ตามที่เครื่องรองรับ, 4K, HDR)
- **ลากแถบเล่นแล้วเห็นภาพตามแบบเรียลไทม์**: ระหว่างลาก วิดีโอบนจอจะ seek ตามนิ้วทันที (ส่ง seek ทีละครั้ง พอเฟรมขึ้นจอก็ไปตำแหน่งล่าสุดต่อ ไม่ค้างคิว) แสดงเวลาละเอียดถึงมิลลิวินาที
  - โหมด **แม่นยำ** (ค่าเริ่มต้น): แสดงเฟรมที่ตรงตำแหน่งจริง
  - โหมด **เร็ว**: กระโดดไป keyframe ใกล้สุด เหมาะกับไฟล์ 4K/ไฟล์ใหญ่
  - ปล่อยนิ้วแล้วจะลงเฟรมที่ตรงเสมอ
- **ปัดซ้าย/ขวาบนจอ** เพื่อเลื่อนเวลาแบบละเอียด (ทั้งจอ = 2 นาที) พร้อมพรีวิวภาพเหมือนกัน
- **ปุ่มเฟรมก่อนหน้า/ถัดไป** เลื่อนทีละ 1 เฟรม
- **ปุ่ม Cap frame** (ปุ่มกล้องสีฟ้าขวาจอ): ถอดเฟรมจากไฟล์ที่ความละเอียดเต็มของวิดีโอ บันทึกเป็น PNG (ไม่เสียคุณภาพ) ไว้ที่ `Pictures/BestPlayer`
- แตะสองครั้ง ซ้าย/ขวา = ย้อน/ข้าม 10 วินาที, ตรงกลาง = เล่น/หยุด
- ปัดขึ้นลงฝั่งซ้าย = ความสว่าง, ฝั่งขวา = เสียง
- ปรับความเร็ว 0.25x–2x, ปรับสัดส่วนภาพ (พอดี/ซูม/ยืด), หมุนจอ
- หน้ารายการวิดีโอในเครื่อง + ปุ่มเปิดไฟล์ และเปิดจากแอพอื่นได้ (Open with)

## Build
ต้องใช้ Android Studio (Ladybug ขึ้นไป) หรือ JDK 17 + Android SDK 35

```
./gradlew assembleDebug
```
APK อยู่ที่ `app/build/outputs/apk/debug/app-debug.apk`

ถ้า push ขึ้น GitHub ระบบ GitHub Actions (`.github/workflows/build.yml`) จะ build APK ให้อัตโนมัติ ดาวน์โหลดได้จากแท็บ Actions → Artifacts

## โครงสร้างโค้ด
- `PlayerActivity.kt` ตัวเล่น, การลากแถบแบบเรียลไทม์, gesture, step เฟรม, cap frame
- `FrameCapture.kt` ถอดเฟรมความละเอียดเต็ม (fallback เป็น PixelCopy) และบันทึกลงแกลเลอรี
- `MainActivity.kt`, `VideoAdapter.kt`, `VideoRepository.kt` หน้ารายการวิดีโอ
